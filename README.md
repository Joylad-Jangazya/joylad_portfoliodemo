# Joylade Jangazya - Portfolio Website

A modern, responsive portfolio website showcasing web development projects and skills.

## Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Dark/Light Theme**: Toggle between themes with persistent storage
- **Accessibility**: WCAG 2.1 compliant with proper ARIA labels and keyboard navigation
- **Modern CSS**: Uses CSS Grid, Flexbox, and custom properties
- **Interactive Elements**: Smooth scrolling, modal galleries, and animated transitions
- **Performance Optimized**: Lazy loading images and efficient CSS/JS

## Project Structure

```
/
├── index.html              # Main portfolio page
├── academy.html            # Educational content page
├── lab.html               # Experimental projects page
├── assets/
│   ├── icons/             # SVG icons and favicons
│   └── images/            # Project images and photos
├── css/
│   ├── reset.css          # CSS reset styles
│   ├── style.css          # Main styles
│   ├── themes.css         # Theme variables
│   ├── grid.css           # Grid system
│   └── components.css     # Reusable components
└── js/
    ├── navigation.js      # Navigation functionality
    ├── theme-switcher.js  # Theme switching
    └── gallery.js         # Gallery modal functionality
```

## Technologies Used

- **HTML5**: Semantic markup and accessibility features
- **CSS3**: Modern styling with Grid, Flexbox, and animations
- **Vanilla JavaScript**: Interactive functionality without frameworks
- **Responsive Images**: Optimized for different screen sizes

## Getting Started

1. Clone or download the project files
2. Open `index.html` in your web browser
3. Navigate through the different sections using the menu

## Customization

### Content
- Update personal information in the hero section
- Replace project descriptions and links
- Add your own images to the `assets/images/` folder
- Modify contact information and social links

### Styling
- Adjust color variables in `css/themes.css`
- Modify layout in `css/style.css`
- Customize component styles in `css/components.css`

### Functionality
- Extend navigation features in `js/navigation.js`
- Add new interactive elements in the respective JS files
- Implement additional themes in `js/theme-switcher.js`
